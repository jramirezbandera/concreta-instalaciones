# Verificación normativa — DB-SUA, Sección SUA 9 «Accesibilidad» y Anejo A (definiciones que usa), para el módulo SUA 9 (feature-20)

**Fecha:** 2026-10-04 · Agente: cte-normativa · **No se ha editado código.**
**Ámbito:** SUA 9 completa (DBSUA pp. 31–34) y las definiciones del Anejo A que SUA 9 usa (pp. 35–41), con los comentarios del Ministerio (DccSUA pp. 52–60 y 61–73). Preguntas D1 a D8 del encargo, en ese orden. SUA 1 (rampa accesible, ap. 4) es de otro agente: aquí solo se cita.

**Regla aplicada:** toda cifra se ha leído en la **imagen** de la página (200 ppp para el DB; 130 ppp para el DccSUA). El texto extraído pierde ≤ y ≥ y la estructura de las tablas. Veredictos:
- **VERIFICADO**: literal en el DB, leído en la imagen de [SUA22] y coincidente con el texto de [SUA22] y de [DccSUA].
- **LEÍDO (1 fuente)**: literal en una sola fuente (un comentario del Ministerio o una ley leída a través de un extractor).
- **CORREGIDO**: lo que dice el encargo no coincide con el DB.
- **NO VERIFICABLE**: el DB no lo dice, o no se ha podido leer con seguridad.
- **INTERPRETACIÓN**: se sigue del DB, pero el DB no lo escribe tal cual. Se puede mostrar, rotulada.
- **CRITERIO**: decisión de proyecto propuesta. No es exigencia del CTE y la ficha la rotula así.

Otros usos: más de dos plantas, o **más de 200 m²** útiles (sin ocupación nula) en plantas sin entrada accesible; plantas con uso público de **más de 100 m²** útiles o con elementos accesibles.
- **1.2.3**: vivienda: 1 plaza accesible por vivienda accesible para silla de ruedas; otros usos con aparcamiento > 100 m² construidos: 1/33 (Comercial, Pública Concurrencia, Aparcamiento de uso público), 1/50 hasta 200 + 1/100 adicionales (resto).
- **1.2.6**: 1 aseo accesible por cada 10 inodoros o fracción.
- **Tabla 2.1** y **ap. 2.2** (0,80–1,20 m; 3±1 / 5±1 mm; 80 cm; 40 cm; UNE 41501:2002).
- **Itinerario accesible**: Ø 1,50; > 10 m; 1,20 m (1,10 m en zonas comunes de Residencial Vivienda); 1,00 / 0,50 / 0,65 m; 0,80 / 0,78 m; 0,80–1,20 m; Ø 1,20; 0,30 m; 25 N / 65 N (puertas de salida); 4 %; 2 %.
- **Mecanismos accesibles**: 80–120 cm (mando y control); 40–120 cm (tomas); ≥ 35 cm al rincón.
- **Plaza accesible**: aproximación lateral ≥ 1,20 m (batería, compartible) o trasera ≥ 3,00 m (en línea); recarga 80–120 cm, 35 cm.
- **Ascensor accesible**: tabla del DB (1,00 × 1,25 / 1,10 × 1,40 / 1,40 × 1,40) **junto con** la tabla corregida (1,00 × 1,30 / 1,10 × 1,40 / 1,40 × 1,60 ó 1,60 × 1,40) rotulada «comentario del Ministerio (15-07-2024), UNE-EN 81-70:2022+A1, desde 21-02-2025».
- **Punto de atención accesible**: 0,80 m; ≤ 0,85 m; 70 × 80 × 50 cm.
- **Aseo accesible** y **vivienda accesible**: cifras de D7.6 y D7.7.

## Cifras que NO deben mostrarse

- **«40 cm a las esquinas»** para mecanismos accesibles: son **35 cm** (D7.3.2).
- **«2,20 × 5,00 m»** como plaza accesible del DB: el DB no fija la plaza (D7.4.3).
- **«1/33 plazas» para oficinas o vivienda**: es solo Comercial, Pública Concurrencia y Aparcamiento de uso público (D5.6).
- **«1,10 m solo en edificios existentes»**: el 1,10 m vale en las zonas comunes de cualquier edificio de viviendas (D7.2.1).
- **Cabina de ascensor por la superficie útil de un edificio de viviendas**: en vivienda decide si hay viviendas accesibles (D7.1.3).
- **Sumar plantas de arriba y de abajo** (−1+PB+2 = 3): el comentario lo descarta (D3.4).
- **Contar las plantas de trasteros o tendederos** para el ascensor (D3.7).
- **Un número de viviendas accesibles «del CTE»**: el DB no lo fija; el 4 % es del RDL 1/2013 y solo para vivienda protegida o pública (D5.2).
- **Exigencias de SUA 9 dentro de una unifamiliar** que no deba ser accesible (D1.6), ni mecanismos accesibles en el interior de las viviendas (D5.15).
- **65 cm de fondo del inodoro como cifra del DB**: el DB dice 75 cm; 65 cm es una tolerancia del comentario (D7.6).
- **«Fuerza de apertura ≤ 25 N» para todas las puertas**: es para las puertas de salida (D7.2.3).

/** «o fracción» = redondeo hacia arriba (comentario DccSUA pp. 57–58). */
export function plazasAccesiblesExigidas(
  uso: UsoPlazas,
  a: { plazas: number; superficieConstruida_m2: number; viviendasAccesiblesSR?: number; alojamientosAccesibles?: number },
): number {
  const d = PLAZAS_ACCESIBLES.datos;
  if (uso === "residencial_vivienda") return d.porViviendaAccesibleSR * (a.viviendasAccesiblesSR ?? 0);
  if (!(a.superficieConstruida_m2 > d.otrosUsosSuperficieConstruida_masDe_m2)) return 0;
  if (uso === "residencial_publico") return a.alojamientosAccesibles ?? 0;
  if (uso === "comercial_pc_o_aparcamiento_publico") return Math.ceil(a.plazas / d.comercialPcAparcamientoPublico_unaCada);
  const { unaCada, hastaPlazas, despues_unaCada } = d.otro;
  if (a.plazas <= hastaPlazas) return Math.ceil(a.plazas / unaCada);
  return Math.ceil(hastaPlazas / unaCada) + Math.ceil((a.plazas - hastaPlazas) / despues_unaCada);
}

/** K2 (INTERPRETACIÓN apoyada en comentarios DccSUA p. 54): plantas a salvar =
 *  máx |nivel − nivelEntrada| entre plantas con viviendas o zonas comunitarias (garaje
 *  incluido), excluidas las plantas que solo tienen zonas de ocupación nula
 *  (trasteros, tendederos, instalaciones). NO se suman las de arriba y las de abajo. */
export function plantasASalvar(
  plantas: readonly { nivel: number; cuenta: boolean }[],
  nivelEntrada = 0, // K1: PB por defecto
): number {
  return plantas.filter((p) => p.cuenta).reduce((m, p) => Math.max(m, Math.abs(p.nivel - nivelEntrada)), 0);
}
